# Soft Bending Actuator

A research-grade soft bending actuator design featuring flexible materials and embedded actuation for use in soft-robotics applications.


## 🎯 Project Overview

This project presents the design, fabrication and testing of a **soft bending actuator** capable of controlled curvature under actuation. Built for use in soft-robotics and bio-inspired manipulation tasks, the actuator uses compliant materials and a smart actuation scheme to achieve bending motion in a compact form factor.

Key features:  
- Compliant structure allowing smooth curvature.  
- Embedded actuation mechanism (e.g., pneumatic/hydraulic or cable-driven).  
- Modular design enabling replication and reuse in soft robotic systems.  
- Documented in full project report including experimental validation.

## 🛠 How to Use

1. Open the `Project.pdf` file to review the design goals, material selection, fabrication method and test results.  
2. Fabricate the actuator according to the described process (moulding/casting, tubing, connectors).  
3. Integrate actuation mechanism and mount relevant sensors/actuators as per guidelines.  
4. Use the results section of the report for benchmarking bending performance and repeatability.

---

## 🔧 Design Considerations

- **Material compliance**: Selected elastomer to allow ~30-60° bend under actuation.  
- **Actuation scheme**: Cable-driven / pneumatic channel embedded in body to enable bending.  
- **Modularity**: Interfaces designed for quick attachment to robotic end-effectors or manipulators.  
- **Performance evaluation**: Included bending angle vs. actuation force curves, fatigue testing and repeatability metrics.
